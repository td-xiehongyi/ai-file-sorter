# React 视觉验收记录

本文用于记录 `ai-file-sorter` React 界面与 [`ai-file-sorter.html`](./ai-file-sorter.html) 的对照验收。页面数据、Provider 状态、文件名和错误信息均以真实运行时结果为准；HTML 中的演示数据不覆盖真实 API。

## 验收尺寸

| 尺寸 | 预期布局 |
| --- | --- |
| 1440px | 260px 侧栏、72px 顶栏、双栏内容按页面需要自适应 |
| 950px | 侧栏收窄为图标栏，设置和结果区域改为单栏 |
| 650px | 隐藏侧栏，工具栏、选择栏、From → To 和操作按钮纵向排列 |

## 视图清单

### 文件浏览

- [x] 未选择目录时显示“选择扫描目录”，不显示空表格操作。
- [x] 已授权目录显示真实路径、索引状态、重新扫描和重建索引。
- [x] 搜索、扩展名/大小/日期筛选、排序和分页保持可用。
- [x] 选中文件显示浅绿色行状态和选择操作栏。
- [x] 选择操作栏提供分类方案、管理分类和分析入口；没有“应用模板”。
- [x] 加载、空结果、索引变化、监听提示和错误状态保持在原位置附近。

### AI 建议审查

- [x] 建议卡片统一显示原文件、摘要、置信度、原因、建议文件名和目标分类。
- [x] 分析中显示进度并禁用重复提交，可取消当前批次。
- [x] 接受建议仍通过操作预览回调，不直接修改磁盘。
- [x] 本地模型不可用时分析按钮禁用，并保留恢复提示。

### 操作预览

- [x] 每条记录以 From → To 对齐展示，并提供完整路径悬停值。
- [x] 冲突或校验失败显示原因，无法确认时不渲染确认按钮。
- [x] “取消计划”和“确认并执行”位于右下方并排显示；忙碌时均禁用。

### 历史与撤销

- [x] 记录显示操作类型、成功/失败/未执行状态和 From/To 路径。
- [x] 只有可撤销记录显示“撤销”；已撤销和不可撤销状态显示文字说明。
- [x] 撤销按钮在请求处理中禁用。

### 模型与分类设置

- [x] 模板库支持新建、查看/修改、重命名、设为全局和删除。
- [x] 全局模板显示为默认分组，可重命名但不显示删除入口；常用模板显示全部模板（包括全局模板），并支持重命名、设为全局和删除。
- [x] 切换不同分类数量的模板时，模板工作区高度和下方内容位置保持稳定，超出内容在面板内部滚动。
- [x] 全局分组和常用模板列表中的同一模板使用相同 ID，切换后编辑器内容保持一致。
- [x] 当前目录自定义分类仍可编辑、启用/禁用、保存和安全删除。
- [x] 页面不提供“应用模板”按钮；模板从文件选择操作栏进入分析前选择。

## 独占视图验收

- [x] 左侧五个导航入口分别渲染文件浏览、AI 建议审查、操作预览、历史与撤销、模型与分类设置。
- [x] 任意时刻主区域只显示当前导航对应的工作区，不再把五类内容纵向堆叠在同一页。
- [x] 没有待确认计划时，操作预览显示明确空状态和返回 AI 审查入口。
- [x] 从文件页进入分类管理后，设置页可返回来源工作区；侧栏直接进入设置时不显示多余返回按钮。
- [x] 分析结果、模板草稿和操作计划由同一控制器保留，切换导航不会静默取消后台任务。

## 状态与安全检查

- [x] 所有主要按钮可通过键盘聚焦，并显示统一焦点环。
- [x] 选择器、输入框和按钮使用可访问名称；忙碌状态暴露禁用状态。
- [x] 200% 缩放和窄屏布局不依赖颜色单独表达状态。
- [x] 移动、重命名、AI 建议和撤销仍经过现有预览、确认、执行时复核、历史和撤销链路。
