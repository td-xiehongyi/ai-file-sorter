| 属性 | 值 |
| --- | --- |

| 最后更新 | `2026-08-18` |

## 文档地位

本文档是第一版文件扫描与文件操作安全规则的规范性来源。产品范围见[产品需求文档](./PRD.md)，模块职责见[系统架构](./ARCHITECTURE.md)，实施顺序见[开发路线图](./ROADMAP.md)。其他项目文档与本文冲突时，涉及安全边界的行为以本文为准。

## 统一术语

- **授权根目录**：用户通过目录选择界面明确允许应用扫描的真实目录。
- **操作草案**：来自用户或未来 AI 的未信任移动或重命名建议，不能直接执行。
- **已校验计划**：Rust 后端根据操作草案和当前磁盘状态生成的短期、一次性计划。
- **预览**：已校验计划的只读展示，至少包含每项操作的 From/To、类型和校验结果。
- **执行结果**：执行后逐项记录的成功、失败或未执行状态及原因。
- **历史记录**：实际文件操作的持久化审计记录。
- **撤销资格**：根据当前磁盘状态动态判断某条成功记录是否还能安全恢复。
- **临时正文**：用户主动发起内容分析后，由 Rust 在本地提取并仅保存在当前任务内存中的原始文本。
- **AI 分析结果**：经过结构校验的摘要、关键词、建议文件名、已有分类 ID、置信度、理由及其来源与文件身份信息。
- **分类 ID**：用户配置并由 Rust 映射到已存在目标目录的稳定标识；AI 不直接决定绝对路径。
- **内容指纹**：内容提取读取文件字节时同步计算、仅用于判断 AI 分析结果是否仍对应当前内容的摘要值；不属于阶段四普通文件操作计划。
- **批次同意凭据**：用户确认一次远程发送范围后生成的短期、一次性授权，绑定确切文件版本、Provider/模型、发送字段和资源预算。

## 不变量

- AI、React 前端和未校验输入都不能直接执行文件系统写操作。
- 目录扫描和监听不能自动读取正文或调用 AI；内容分析必须由用户明确选择文件并主动发起。
- 临时正文不能写入 SQLite、操作历史、应用日志或扫描目录旁车文件。
- 文件系统始终是真实文件状态的最终事实，SQLite 不能替代执行前磁盘复核。
- 第一版绝不覆盖现有文件或目录。
- 没有有效预览计划和用户确认，不能执行移动或重命名。
- 预览、校验失败、取消和超时不能产生成功执行记录。
- 所有实际执行结果必须与磁盘真实状态一致。

## 扫描授权边界

- 应用只能扫描用户明确选择的授权根目录。
- 默认不跟随符号链接、Windows Junction 或其他目录重解析点。
- 索引可以记录链接条目及其基础元数据，但不能自动进入链接目标。
- 用户需要扫描链接目标时，必须单独选择目标的真实目录，使其成为新的授权根目录。
- 扫描器和文件监听器遵守同一边界，不能通过链接扩展到未授权目录。
- 路径归属必须基于规范化路径和平台文件系统语义判断，不能只比较字符串前缀。
- 循环链接、损坏链接和指向授权范围外的链接不得导致递归遍历或扫描失败扩散。

## SQLite 数据边界

- SQLite 数据库统一存放在操作系统为应用提供的应用数据目录中。
- 扫描根目录中不得创建数据库、索引文件、旁车元数据目录或其他应用文件。
- 数据库路径由 Rust 后端通过系统应用数据目录 API 解析；前端不能传入或覆盖数据库路径。
- 文件索引是可重建数据，可以通过重新扫描授权根目录恢复。
- 操作历史不能随索引重建清除。
- AI 分析结果可以持久化，但只能包含摘要、关键词、建议、置信度、理由、Provider/模型标识、分析时间、文件身份、内容指纹和采用状态；不得包含临时正文。
- 重建索引只能清理索引相关数据，不能通过删除整个数据库文件实现。

## 第一版操作范围

- 只支持普通文件的移动和重命名。
- 移动的目标目录必须已经存在。
- 不创建、移动或重命名目录。
- 不删除文件或目录，也不注册删除 Command、删除执行器或删除界面。
- 跨平台可恢复删除必须作为独立方案重新设计和确认后才能加入。

## 草案、校验、预览与确认

```text
用户输入或 AI 建议
  → 操作草案
  → Rust 全量校验
  → 已校验计划与预览
  → 用户确认 planId
  → Rust 执行前复核
  → 逐项执行
  → 执行结果与历史记录
```

- 前端只能提交结构化操作草案，不能要求后端执行任意路径操作。
- Rust 对整批草案执行全量校验；存在任一无效项时，不生成可确认计划。
- 预览必须与已校验计划来自同一份后端状态。
- 前端确认时只提交 `planId`，不能重新提交或替换源路径、目标路径和操作类型。
- Rust 执行前必须再次复核磁盘状态，不能因为用户看过预览而跳过复核。

## `planId` 生命周期

- `planId` 由 Rust 后端生成，计划只保存在内存，不写入 SQLite。
- 生命周期状态包括：有效、已消费、已取消、已过期；后三者为终态。
- 有效期固定为生成后 10 分钟。
- 执行请求开始后立即消费，不能重复执行。
- 用户取消、超过有效期或应用退出都会使计划失效。
- 无效、已消费、已取消或已过期的 `planId` 必须被拒绝，且不能产生文件变化。

## 执行前文件身份复核

- 校验计划至少记录规范化源路径、规范化目标路径、文件类型、大小和修改时间。
- 平台能够稳定提供文件身份标识时，同时记录并复核该标识。
- 执行前重新读取以上信息；与计划快照不一致时拒绝该项并按批量失败规则停止。
- 第一版的手动普通操作不计算文件内容哈希，避免对大文件产生额外完整读取成本；AI 派生计划按“AI 权限边界”复核内容提取时已有的内容指纹。
- 手动操作不使用内容哈希不降低目标冲突、路径边界或文件类型检查要求。

## 目标冲突与覆盖策略

- 目标路径存在任何文件或目录时即视为冲突。
- 冲突在预览中明确标记，并阻止生成可确认计划。
- 第一版不提供覆盖、替换、自动合并、自动编号或静默改名。
- 用户必须修改目标名称或位置，然后重新提交草案并重新校验。
- 执行前若目标路径新出现，当前项失败并停止后续项目；不得覆盖目标。
- 撤销时目标恢复位置被占用，同样拒绝撤销，不覆盖现有内容。

## 卷边界

- 第一版只支持源文件与目标目录位于同一磁盘或文件系统的移动。
- 跨磁盘或跨文件系统移动在预览校验阶段标记为不支持，并阻止确认。
- 第一版不把跨卷移动降级为复制，也不执行“复制、校验、删除源文件”的替代流程。
- 跨卷能力需要独立定义完整性校验、失败恢复、历史和撤销后才能加入。

## 批量执行与失败

- 确认前必须全量校验所有项目；任一无效项都会阻止整批确认和执行。
- 用户确认后，执行器按已校验顺序逐项执行，并在每项开始前复核磁盘状态。
- 首个运行时失败发生后，立即停止所有尚未开始的后续项目。
- 文件系统批量操作不声明数据库式原子性。
- 不自动回滚已经成功的项目，避免二次失败掩盖真实磁盘状态。
- 每项结果只能是成功、失败或未执行；批次结果由逐项真实状态汇总。
- 失败或未执行项目不能生成虚假的成功记录或撤销记录。
- 已成功项目通过正常撤销流程逐项恢复。

## 历史与撤销资格

- 操作历史默认长期保留，不做自动到期清理。
- 只有实际成功的移动或重命名生成可供撤销判断的历史记录。
- 历史记录存在不代表当前仍然可以撤销。
- 展示历史和执行撤销前都应根据当前磁盘状态重新计算撤销资格。
- 源恢复位置被占用、已移动文件不存在、文件身份不匹配或权限不足时，撤销资格为不可用并给出原因。
- 撤销不能覆盖现有文件或目录。
- 批量操作中已成功项目可以逐项撤销；失败和未执行项目不可撤销。
- 重建文件索引后，历史记录和仍然有效的撤销资格信息必须保留。

## AI 权限边界

- 第一版 AI 不生成删除、目录操作、覆盖或跨卷移动建议。
- 第一版内容提取只支持文本型 PDF、TXT、MD 和 DOCX；旧版 `.doc`、XLSX、PPTX、OCR 和多模态理解不在范围内。
- AI 只能返回封闭的严格结构：`summary` 为非空字符串，`keywords` 为非空字符串数组，`suggested_filename` 为不含路径且扩展名与源文件一致的合法文件名，`category_id` 为已有分类 ID 或 `null`，`confidence` 为 `[0, 1]` 范围内的数字，`reason` 为非空字符串。缺少字段、额外字段、类型错误、空必填值或越界值时整项拒绝；通过校验并由用户接受后，结果才能转换为与用户输入相同格式的操作草案。
- AI 不能返回或影响绝对目标路径，不能请求创建目录。未知分类 ID 被拒绝；无法匹配现有分类时只允许重命名建议。
- AI 不能获得 `planId` 的执行权限，不能直接调用执行、历史清理或撤销服务。
- 用户接受 AI 建议后，建议仍须经过 Rust 校验、预览和明确确认。
- 使用远程 Provider 时，批次同意凭据必须绑定确切文件及内容指纹、Provider/模型、拟发送字段、预计字符或 token 数、分段与调用次数、最大重试预算和费用范围；Provider 无法估算费用时必须明确显示“无法估算”。凭据在任一绑定项变化、超预算、取消、消费或过期后失效，未持有有效凭据时不得发送正文。
- 临时正文只在内容提取、分段和 Provider 调用所需的任务内存中存在，任务完成、失败或取消后释放，不得进入持久化层或日志。
- 内容提取必须在读取字节时同步计算内容指纹，并在提取结束及持久化前复核文件元数据与平台身份；分析期间变化时丢弃结果。持久结果绑定内容指纹，应用重启后加载或转换为操作草案前按需重新计算。AI 派生的草案和已校验计划必须携带该指纹，Rust 执行前再次计算并复核；不一致时结果或计划失效。手动普通操作第一版仍不强制计算内容哈希。
- 扫描 PDF、加密或损坏文档、空文本、格式伪装、解码失败、资源超限、Provider 失败或非法输出均不得产生可执行建议。
- AI 不可用、输出非法或用户拒绝建议时，基础文件管理功能必须继续正常工作。

## 禁止暴露的接口

- 任意 Shell 命令执行接口。
- 接受任意命令名的 Tauri 调用包装器。
- 接受未经计划绑定的任意源路径和目标路径执行接口。
- 跳过校验、预览或确认的移动与重命名接口。
- 删除、覆盖、目录操作和跨卷移动接口。
- 接受 AI 提供的绝对路径、未知分类 ID 或目录创建请求并直接转换为操作草案的接口。
- 绕过批次同意向远程 Provider 发送正文的接口，或将临时正文写入 SQLite、历史或日志的接口。
- 由前端指定 SQLite 文件位置或直接执行 SQL 的接口。

## 必须覆盖的安全测试

- 未授权路径、字符串前缀伪装路径、符号链接、Junction、循环链接和损坏链接。
- 扫描目录无旁车文件，索引重建保留操作历史。
- 普通文件以外的对象、缺失目标目录和跨卷移动被拒绝。
- 目标在校验时已存在或执行前新出现时均不覆盖。
- `planId` 过期、取消、重复消费和应用会话失效。
- 预览后源文件类型、大小、修改时间或平台文件身份变化。
- 批量预检失败时零执行；运行时失败后后续项目保持未执行。
- 成功、失败、未执行状态与磁盘真实状态一致。
- 历史长期保留，撤销资格随冲突和文件状态变化正确更新。
- AI 输出无法绕过草案、校验、预览、确认和执行权限边界。
- 文本型 PDF、TXT、MD 和 DOCX 的内容分析结果符合封闭 schema；缺少字段、额外字段、类型错误、空必填值、非法文件名和越界置信度被拒绝，长文档分段汇总不会绕过批次同意与结果校验。
- 扫描 PDF、加密或损坏文档、空文本、格式伪装、不支持格式、解码失败和资源超限不会调用 Provider 或产生可执行建议。
- 未取得本批远程发送同意时零正文外发；临时正文不会出现在 SQLite、操作历史、应用日志或扫描目录中。
- 有效分类 ID 可由 Rust 映射到现存目录并进入完整安全执行链；未知分类 ID、绝对路径和目录创建输出被拒绝。
- 同大小或相同修改时间的内容替换、分析期间变化、应用重启后加载结果，以及 AI 草案生成后至执行前的变化，都会被内容指纹复核发现并使旧结果或计划失效。
