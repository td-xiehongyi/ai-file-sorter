## 文档目的

本文档只说明当前目录结构、模块职责、依赖方向和测试文件归属。文件扫描与操作的规范性安全规则见 [安全模型](./SAFETY_MODEL.md)，分阶段建设内容见 [开发路线图](./DEVELOPMENT_ROADMAP.md)。

## 顶层目录

### `MD/`

- 存放项目结构、安全模型、开发路线图和后续技术决策文档。
- 不存放应用运行时读取的数据或生成物。

### `src/`

- React 与 TypeScript 前端源码根目录。
- 负责界面展示、用户交互和结构化请求提交。
- 不直接访问本地文件系统、SQLite 或操作系统 Shell。

### `src-tauri/`

- Tauri 与 Rust 后端根目录。
- 负责本地文件访问、程序校验、SQLite 持久化和受控文件操作。
- 不向前端暴露任意文件系统访问或 Shell 执行能力。

## 前端目录

### `src/app/`

- React 应用入口、根布局、全局样式和应用级组合逻辑。
- 可以组合业务 feature，但不承载具体文件管理规则。

### `src/components/`

- 存放无业务含义的共享 UI 组件，例如按钮、对话框、表格外壳和状态提示。
- 不直接调用 Tauri Command，也不包含扫描、文件操作或 AI 规则。

### `src/features/files/`

- 文件浏览相关前端功能。
- 后续承载目录选择、扫描进度、文件列表、排序、筛选、搜索和变化提示。
- 只通过 `src/lib/` 中的受控接口请求后端能力。

### `src/features/operations/`

- 安全文件操作相关前端功能。
- 后续承载操作草案、预览、确认、执行结果、历史和撤销资格展示。
- 不直接构造或调用文件系统写操作。

### `src/lib/`

- 前端基础设施与外部边界封装。
- 后续集中封装窄化的 Tauri 调用和错误转换。
- 不提供接受任意命令名、任意路径操作或 Shell 命令的通用包装器。

### `src/types/`

- 前端共享的 TypeScript 数据类型。
- 后续描述文件条目、搜索条件、操作草案、预览、执行结果和历史记录。
- 类型必须与 Rust 对外数据保持一致，但不能包含文件执行逻辑。

## Rust 后端目录

### `src-tauri/src/commands/`

- Tauri Command 的唯一入口目录。
- Command 只接收结构化请求、调用 service，并返回结构化结果。
- 不直接实现复杂业务逻辑，不开放任意文件系统或 Shell 接口。

### `src-tauri/src/models/`

- Rust 领域模型和跨层数据结构。
- 后续承载文件元数据、扫描结果、操作草案、已校验计划、执行结果和历史状态。
- 未校验数据与可执行计划必须使用不同结构表达。

### `src-tauri/src/services/`

- 核心业务逻辑目录。
- 后续承载扫描、搜索、文件监听、路径策略、操作校验、安全执行和撤销资格判断。
- AI 模块只能生成操作草案，不能直接访问执行服务。

### `src-tauri/src/storage/`

- 本地持久化边界。
- 后续承载应用数据路径、SQLite 连接、迁移、索引仓储和操作历史仓储。
- 文件系统是真实文件状态的最终事实；数据库只保存索引和应用元数据。
- 前端不能直接访问 SQLite。

## 核心依赖方向

```text
React feature
  → src/lib 中的受控 Tauri 调用
  → commands
  → services
  → models / storage / 本地文件系统
```

AI 功能加入后仍须遵循：

```text
AI 建议
  → 操作草案
  → Rust 校验与预览计划
  → 用户确认
  → 安全执行
  → 历史记录
  → 撤销资格判断
```

## 安全规则摘要

- 第一版只处理普通文件的同卷移动与重命名，不提供删除或目录操作。
- 文件扫描、SQLite、预览确认、冲突处理、批量失败和撤销规则以 [安全模型](./SAFETY_MODEL.md) 为准。
- 目录说明与安全模型冲突时，以安全模型中的规范性规则为准。

## 测试文件归属

- 测试随功能阶段同步建设，不推迟到发布阶段统一补写。
- 前端组件和 hook 的单元测试与被测文件放在同一 feature 目录，使用 `.test.ts` 或 `.test.tsx` 后缀。
- Rust 单元测试优先放在对应模块内部；涉及 SQLite、文件系统或多个模块的测试放入未来的 `src-tauri/tests/`。
- 跨前后端桌面端到端测试放入未来的 `tests/e2e/`。
- 所有文件系统和 SQLite 测试只能使用隔离临时目录与测试数据库。
- `src-tauri/tests/` 与 `tests/e2e/` 均为未来规划目录，当前尚未创建。
